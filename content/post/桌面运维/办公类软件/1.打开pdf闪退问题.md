解决Win10下PDF闪退问题
===============


问题描述
----


升级 Windows 10 后，很多人会遇到利用 Adobe Reader 打开pdf文件3秒后闪退的问题，这很可能是因为Adobe需要联网验证授权失败导致的，可使用 netsh advfirewall 工具禁止Adobe程序out出站流量，以达到屏蔽验证的目的。


解决方案
----


* 第1步，以管理员身份运行cmd命令提示符，执行如下命令，找到 pdf 安装文件目录（通常软件都默认安装在 %ProgramFiles(x86\)% 下面）



```
where /R "C:\Program Files (x86)" AcroRd32.exe

```

返回结果如下：



```
C:\Program Files (x86)\Adobe\Reader 11.0\Reader\AcroRd32.exe

```

* 第2步，在当前cmd命令提示符下，执行如下命令，将该exe执行文件加入到防火墙出站的黑名单即可。



```
netsh advfirewall firewall add rule name="block_adobe_network" dir=out action=block program="C:\Program Files (x86)\Adobe\Reader 11.0\Reader\AcroRd32.exe" enable=yes

```
