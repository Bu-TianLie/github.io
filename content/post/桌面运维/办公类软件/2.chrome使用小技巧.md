实用的chrome插件
-----------


### 插件的在线安装


* Chrome地址栏打开 [谷歌应用商店](https://chrome.google.com/webstore/category/extensions?utm_source=chrome-ntp-icon)（要有vpn才可以打开），搜索如下插件并安装：




| 名称 | 功能 | 简介 | 推荐指数 |
| --- | --- | --- | --- |
| AdGuard | 广告拦截器 | 可拦截所有网页上的所有类型的广告 | ★★★★★ |
| Tampermonkey BETA | 免费看vip视频 | 免费破解vip视频、去广告、下载百度文库付费文档等 | ★★★★★ |
| OneTab | 标签页管理器 | 保存所有标签页，重启机器后可单独或全部恢复标签页 | ★★★★ |
| Dark Reader | 黑暗主题 | 关爱眼睛，实时生成黑暗主题 | ★★ |


### 插件的导出


* 1、Chrome地址栏粘贴 chrome://extensions 并打开，打开右上角的 开发者模式 开关（否则看不到插件的ID字符串），找到想要导出的插件（记住ID 后面那一串字符）


[![Alt text](http://static.sqlfans.cn/file/20211203/chrome-extensions-outport.png)](http://static.sqlfans.cn/file/20211203/chrome-extensions-outport.png)


* 2、打开Chrome插件的本地目录，找到上一步那一串字符对应的插件目录，打个压缩包，以供该插件的离线安装所用。



```
%USERPROFILE%\AppData\Local\Google\Chrome\User Data\Default\Extensions

```

### 插件的离线安装


* 1、下载想要安装的插件的压缩包




| 名称 | 下载地址 (请右键"链接另存为") |
| --- | --- |
| AdGuard | [adguard.zip](http://iso.sqlfans.cn/windows/chrome/adguard.zip) |
| Tampermonkey BETA | [tampermonkeybeta.zip](http://iso.sqlfans.cn/windows/chrome/tampermonkeybeta.zip) |
| OneTab | [onetab.zip](http://iso.sqlfans.cn/windows/chrome/onetab.zip) |
| Dark Reader | [darkreader.zip](http://iso.sqlfans.cn/windows/chrome/darkreader.zip) |


* 2、 建议解压到如下目录



```
%USERPROFILE%\AppData\Local\Google\Chrome\User Data\Default\Extensions

```
* 3、Chrome地址栏粘贴 chrome://extensions 并打开，点击左上角的 加载已解压的扩展程序，选择解压之后带版本号的那一级子目录，即可完成安装。


[![Alt text](http://static.sqlfans.cn/file/20211203/chrome-extensions-inport.png)](http://static.sqlfans.cn/file/20211203/chrome-extensions-inport.png)

### 设置Chrome的字符编码


**问题描述**


在Google Chrome浏览器中拖拽安装Charset插件，出现无效:"CRX\_HEADER\_INVALID"问题。


**解决办法**


* 1\.把下载好的 [Charset\_v0\.4\.1\.crx](http://iso.sqlfans.cn/windows/chrome/Charset_v0.4.1.crx) 改成.zip或者.rar；
* 2\.使用压缩软件(如winrar)对该压缩文件进行解压；
* 3\.打开 Chrome浏览器 \-\> 更多工具 \-\> 扩展程序，选择右上角"开发者模式" \-\> 点击左上角"加载已解压的扩展程序"，选择刚刚解压的Chrome插件文件夹；
* 4\.Chrome插件即可安装成功；
