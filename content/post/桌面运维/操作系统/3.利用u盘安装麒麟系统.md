制作开机启动盘
-------


1、制作开机启动u盘，请参考 `制作启动u盘`


2、下载 Kylin\-Server\-10\-SP1\-Release\-Build20\-20210518\-x86\_64\.iso 并将其拷贝到u盘根目录


开始安装银河麒麟 v10
------------


下面以 联想SR558H 上安装 **银河麒麟v10** 系统为例。


第1步，将u盘插入需要安装麒麟系统的服务器，开机按 DELETE 进入 BIOS，调整USB设备启动


第2步，如下界面选择 `Install Kylin Linux Advanced Server V10`


[![](https://static.sqlfans.cn/file/20210114/kylin-1-begin.png)](https://static.sqlfans.cn/file/20210114/kylin-1-begin.png)


第3步，语言选择 `English`


[![](https://static.sqlfans.cn/file/20210114/kylin-2-language.png)](https://static.sqlfans.cn/file/20210114/kylin-2-language.png)


第4步，确认系统的相关配置


[![](https://static.sqlfans.cn/file/20210114/kylin-3-begin.png)](https://static.sqlfans.cn/file/20210114/kylin-3-begin.png)


第5步，选择系统安装的目标设备


[![](https://static.sqlfans.cn/file/20210114/kylin-4-local-disks.png)](https://static.sqlfans.cn/file/20210114/kylin-4-local-disks.png)


第6步，建议选择最小化安装


[![](https://static.sqlfans.cn/file/20210114/kylin-5-minimal-install.png)](https://static.sqlfans.cn/file/20210114/kylin-5-minimal-install.png)


第7步，安装过程中配置一下 root 密码


[![](https://static.sqlfans.cn/file/20210114/kylin-6-root-password.png)](https://static.sqlfans.cn/file/20210114/kylin-6-root-password.png)


第8步，确认许可信息


[![](https://static.sqlfans.cn/file/20210114/kylin-7-license.png)](https://static.sqlfans.cn/file/20210114/kylin-7-license.png)


第9步，进入系统，执行如下命令，确认一下网卡设备，这里以 `ens18` 为例：



```
ip a

```

第10步，配置ip地址，这里以 `ens18` 为例：



```
vi /etc/sysconfig/network-scripts/ifcfg-ens18

...

BOOTPROTO=static
ONBOOT=yes
IPADDR=192.168.4.250
PREFIX=24
GATEWAY=192.168.4.254
DNS1=192.168.3.10

```

第11步，重启网卡生效



```
ifdown ens18
ifup ens18

```

遇到的问题
-----


### 场景1：报错 Failed to load ldlinux.c32


**遇到的问题**：


用 Ventoy 制作启动u盘，在 联想SR558H 上安装银河麒麟v10系统，选择从U盘启动后报错 Failed to load ldlinux.c32



```
Failed to load ldlinux.c32
Boot failed: please change disks and press a key to continue.

```

**过程分析**：


1. 怀疑是制作的U盘有问题，换一个U盘用同样方法制作，问题依旧。
2. 怀疑是U盘插的USB接口有问题，更换至服务器后面USB接口，问题依旧。
3. 查阅资料，发现是U盘制作工具有问题，更换U盘制作工具为 [Universal\-USB\-Installer\-2\.0\.0\.8](http://iso.sqlfans.cn/os/pe/Universal-USB-Installer-2.0.0.8.exe)，问题解决。


**解决方法**：


使用 Universal\-USB\-Installer\-2\.0\.0\.8 工具制作安装U盘，制作步骤如下，其它类型操作系统制作方法类似。


[![](https://static.sqlfans.cn/file/20210114/kylin-universal-usb.png)](https://static.sqlfans.cn/file/20210114/kylin-universal-usb.png)


### 场景2：bios配置raid


开机按 DELETE 进入 BIOS \- 高级 \- UEFI HII配置 \- AVAGO  Configuration Utility \- Configure \- Create Virtual Drive \- Select RAID Level，可配置RAID级别


### 场景3：格式化磁盘


若重装系统的时候，老的磁盘已经有数据，则需要将老的磁盘格式化，下面是详细步骤以供参考：


第1步，选择系统安装的目的设备


[![](https://static.sqlfans.cn/file/20210114/kylin-3-begin.png)](https://static.sqlfans.cn/file/20210114/kylin-3-begin.png)


第2步，选中磁盘后，`Storage Configuration` 选中 Custom，并点 Done


[![](https://static.sqlfans.cn/file/20230104/kylin-21-disk-custom.png)](https://static.sqlfans.cn/file/20230104/kylin-21-disk-custom.png)


第3步，通过点击【\-】将老的分区全部删掉


[![](https://static.sqlfans.cn/file/20230104/kylin-22-delete-it.png)](https://static.sqlfans.cn/file/20230104/kylin-22-delete-it.png)


第4步，删完老的分区之后，重新配置分区，选择 Click here to create them automatically


[![](https://static.sqlfans.cn/file/20230104/kylin-23-automatically.png)](https://static.sqlfans.cn/file/20230104/kylin-23-automatically.png)


第5步，通过点击【\-】删掉不用的分区，比如 `/backup`


[![](https://static.sqlfans.cn/file/20230104/kylin-24-delete-mount.png)](https://static.sqlfans.cn/file/20230104/kylin-24-delete-mount.png)


第6步，将删掉的分区空间划给根目录。可将根目录的 Desired Capacity 调大，系统会自动匹配到可用的最大空间



> 注：系统默认采用 xfs 文件系统，龙芯平台默认采用 ext4 文件系统。推荐使用 ext4 文件系统


[![](https://static.sqlfans.cn/file/20230104/kylin-25-desired-capacity.png)](https://static.sqlfans.cn/file/20230104/kylin-25-desired-capacity.png)


第7步，点 Accept Changes 接受，则完成磁盘格式化。


[![](https://static.sqlfans.cn/file/20230104/kylin-26-accept-changes.png)](https://static.sqlfans.cn/file/20230104/kylin-26-accept-changes.png)


### 场景4：安装报错 An unknown error has occurred.


**遇到的问题**：


2023\.05\.18\.将一台服务器（联想SR558H）从`pve 7.2系统`装回`银河麒麟v10 sp1系统`的时候，输入密码之后（进度条为`设置存储设备`）弹出如下报错窗口：



```
An unknown error has occurred.

This program has encountered an unknown error. You may report the bug below or quit he program.

More info...
The output below may help determine the cause of the error:

anaconda 29.24.7 exception report
Traceback (most recent call first):
 File "/usr/lib/python3.7/site-packages/blivet/formats/_init_.py", line 577, in_destory raise FormatDestoryError(msg)

```

**解决方法**：


考虑到这个报错（ `FormatDestoryError` ）是和磁盘格式化销毁有关，通过如下尝试并得到了解决：


* 第1步，安装centos系统并未报错，再重启机器
* 第2步，安装银河麒麟v10系统，安装之前先删除老的系统分区
