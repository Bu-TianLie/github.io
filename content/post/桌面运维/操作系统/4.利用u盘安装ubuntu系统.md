配置ip地址
------


* 第15步，进入系统，配置ip地址，参考如下：


ubuntu 20\.04 配置静态ip参考：



```
sudo vim /etc/netplan/00-installer-config.yaml

network:
  ethernets:
    ens18:
      addresses:
      - x.x.x.227/24
      gateway4: x.x.x.254
      nameservers:
        addresses:
        - 8.8.8.8
        search: []
  version: 2

```

ubuntu 22\.04 配置静态ip参考（注意 routes及via 的位置）：



```
sudo vim /etc/netplan/00-installer-config.yaml

network:
  ethernets:
    ens18:
      addresses:
      - x.x.x.228/24
      routes:
        - to: default
          via: x.x.x.254
      nameservers:
        addresses:
        - 8.8.8.8
  version: 2

```

* 第16步，启用网卡



```
sudo netplan apply

```
