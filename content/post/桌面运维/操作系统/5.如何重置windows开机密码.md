利用pe重置windows开机密码
=================


假如是忘记了 Windows 开机密码，该怎么办呢？只有重装系统了吗？显然不是的，可以借助PE U盘启动盘来轻松解决这个问题。


注：适用于win7、win8、win10、win2012、win2016、win2019等系统，下文以**重置 win2019 开机密码**为例。


**重置开机密码过程**


1、将U盘设置为启动盘，可参考 [新毛桃制作启动u盘](http://www.xinmaotao.net/jiaocheng/upqdzz.html)


2、下载 [EasyU\_v3\.5\.iso](http://iso.sqlfans.cn/os/pe/EasyU_v3.5.iso) 并拷贝到 U盘


3、将制作好的u盘插入电脑，重启


4、开机不停的按 F8 进入 BIOS，设置从U盘启动（下面以烧录iso光盘启动为例）


5、看到如下提示，按任意键，进入下一步



```
Press any key to boot from CD or DVD ......

```

6、进入 `Windows Boot Manager`，选择 \[2] Windows 10 PE x64 (1024x768\)，按回车



```
Choose an operating system to start, or press TAB to select a tool:

[1] Windows 10 PE x64
[2] Windows 10 PE x64 (1024x768)

To specify an advanced option for this choice, press F8.

```

7、进入pe系统，依次选择 开始 \- 程序 \- 密码相关 \- NTPWEDIT(密码破解工具)，如下图所示：


[![](https://static.sqlfans.cn/file/20210113/win-password-reset-1.png)](https://static.sqlfans.cn/file/20210113/win-password-reset-1.png)


8、打开 NTPWEdit 界面，打开默认的 SAM 文件路径，选择要重置的用户名，再点“修改密码”，如下图所示：


[![](https://static.sqlfans.cn/file/20210113/win-password-reset-2.png)](https://static.sqlfans.cn/file/20210113/win-password-reset-2.png)


9、保存修改后，重启机器。完工
