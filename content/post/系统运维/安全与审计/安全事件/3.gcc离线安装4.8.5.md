gcc离线安装
=======


通常，最小化安装 centos 7\.9 无gcc环境，如果yum有效的话可以通过 `yum install -y gcc-c++ glibc-static gcc` 来安装gcc环境，但在特定场景只能离线安装的话，就需要安装太多的依赖，下面介绍一下gcc离线安装的方法。


* 第1步，确认gcc没有安装



```
[root@localhost ~]# gcc --version
-bash: gcc: command not found

```

* 第2步，下载gcc依赖的所有rpm包



```
[root@localhost ~]# cd /opt
[root@localhost ~]# wget -c http://iso.sqlfans.cn/linux/gcc-4.8.5.zip
[root@localhost ~]# unzip gcc-4.8.5.zip
```

* 第3步，通过rpm的方式安装gcc



```
[root@localhost ~]# cd /opt/gcc-4.8.5
[root@localhost ~]# rpm -Uvh *.rpm --nodeps --force

```
