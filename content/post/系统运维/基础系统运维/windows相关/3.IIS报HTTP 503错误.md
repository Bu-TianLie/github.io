IIS报HTTP 503错误
==============


**故障上报**


* 由于ecs欠费冻结导致网站无法访问，待续费完成之后，某iis站点打开报 503 错误
* 打开iis看到该站点所使用的应用程序池处于失败状态，启动之后再次刷新则又失败
* 打开 事件查看器 \- Windows日志 \- 应用程序，看到大量如下 2307 错误，详细如下：



```
日志名称：应用程序
来源：IIS-W3SVC-WP
事件ID：2307
级别：错误
常规：应用程序池“xxx”的工作进程在尝试从文件“\\?\<EMPTY>”的第“0”行读取配置数据时遇到错误“无法读取配置文件 ”。数据字段包含错误代码。

```

* 如下是版本信息：



```
操作系统：Windows Server 2012 R2 Datacenter x64
IIS版本：Internet Information Services (Version 8.5.9600.16384)

```

**解决办法**


* 删除 无用的应用程序池（可选）
* 打开 C:\\inetpub\\temp\\appPools 删除无用的引用程序池所对应的目录，并删除该站点所用到的应用程序池所对应的目录（此时该应用程序池为停止状态）
* 启动 该站点所用到的应用程序池，再次刷新页面就ok了
