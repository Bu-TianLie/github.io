linux系统配置ip地址
=============


* 执行 `ifconfig` 确认服务器有几片网卡，以及要在哪片网卡上配置ip地址，比如 eth0


[![](https://static.sqlfans.cn/file/20111013/os-ip-ifconfig.png)](https://static.sqlfans.cn/file/20111013/os-ip-ifconfig.png)


* 进入网卡配置文件目录，找到对应网卡的配置文件，比如 eth0网卡 对应的配置文件就是 ifcfg\-eth0



```
cd /etc/sysconfig/network-scripts
ls

```

[![](https://static.sqlfans.cn/file/20111013/os-ip-sysconfig.png)](https://static.sqlfans.cn/file/20111013/os-ip-sysconfig.png)


* 执行 `vi ifcfg-eth0` 修改对应网卡的配置文件（只用修改 ONBOOT、BOOTPROTO、IPADDR、NETMASK、GATEWAY 这几个参数，如果没有就手动添加，其他参数不要动）



```
[root@u-228234-wiki network-scripts]# vi ifcfg-eth0

NAME=设备名             #.勿动!
UUID=设备唯一标识符        #.勿动!
DEVICE=设备名            #.勿动!
HWADDR=MAC地址            #.勿动!
TYPE=Ethernet            #.勿动!

ONBOOT=yes              #.默认为no，请改为yes
BOOTPROTO=static        #.获取IP的方式：默认dhcp表示动态分配,请修改为static表示静态
IPADDR=IP地址            #.IP地址，比如：192.168.11.70
NETMASK=子网掩码        #.子网掩码，比如：255.255.255.0
GATEWAY=网关地址        #.网关地址，比如：192.168.11.1

```

* 按 i 键进入编辑模式，左下角会显示 [![](https://static.sqlfans.cn/file/20111013/vi.png)](https://static.sqlfans.cn/file/20111013/vi.png)
* 编辑完成按 Esc 退出编辑模式，然后按 :wq 保存配置，这个也会在左下角显示 [![](https://static.sqlfans.cn/file/20111013/wq.png)](https://static.sqlfans.cn/file/20111013/wq.png)
* 最后重启下对应网卡，使其生效，比如 eth0



```
ifdown eth0
ifup eth0

```
