如何查询本机的外网ip地址
=============


linux 如何查询外网ip地址
----------------


### curl 纯文本格式输出



```
curl icanhazip.com
curl ifconfig.me
curl ipinfo.io/ip
curl ipecho.net/plain

```

### curl JSON格式输出



```
curl ipinfo.io/json
curl ifconfig.me/all.json
curl www.trackip.net/ip?json

```

### curl XML格式输出



```
curl ifconfig.me/all.xml

```

### wget 纯文本格式输出



```
wget http://ipecho.net/plain -O - -q ; echo

```

### 建议配置 alias 方便查询


建议配置 alias 方便日常查询，比如：



```
alias ipe='curl icanhazip.com'
ipe

```
