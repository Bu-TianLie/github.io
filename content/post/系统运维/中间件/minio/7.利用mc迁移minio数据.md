利用mc迁移minio数据
=============


本篇详细讲述如何利用mc将minio数据从节点1迁移到节点2中，示例环境如下：



```
源头minio节点：10.30.3.231
目标minio节点：10.30.3.232

```

* 1\.源节点：下载最新版的 mc客户端



```
curl -sL http://iso.sqlfans.cn/linux/mc.2023-08-15 -o /usr/bin/mc
chmod +x /usr/bin/mc

```

* 2\.源节点：针对2个minio节点，创建2个别名



```
mc alias set minio1 http://10.30.3.231:9000 minioadmin minioadmin --api s3v4
mc alias set minio2 http://10.30.3.232:9000 minioadmin minioadmin --api s3v4
mc alias list

```

* 3\.源节点：模拟源节点（minio1）某bucket已存在文件，示例 `bucket111`



```
mc mb minio1/bucket111
mc cp /etc/hosts minio1/bucket111
mc cp /etc/sysconfig minio1/bucket111 --recursive

```

* 4\.源节点：为目标节点（minio2）创建bucket，并利用cp命令实现一次数据同步



```
mc mb minio2/bucket111
mc cp --recursive minio1/bucket111 minio2

```
