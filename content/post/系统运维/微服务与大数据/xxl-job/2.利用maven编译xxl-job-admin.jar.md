如何利用maven编译xxl\-job\-admin.jar
==============================


* 下载 xxl\-job 最新的源码包，再利用maven编译出 xxl\-job\-admin.jar



```
#.1.安装maven
cd /opt/
wget -c http://iso.sqlfans.cn/linux/apache-maven-3.6.3-bin.tar.gz
tar -zxvf apache-maven-3.6.3-bin.tar.gz
mv apache-maven-3.6.3 /usr/local/maven3

#.2.下载xxl-job-2.4.1
cd /opt/
wget -c http://iso.sqlfans.cn/linux/xxl-job-2.4.1.tar.gz
tar xvf xxl-job-2.4.1.tar.gz

#.3.利用mvn编译xxl-job
cd /opt/xxl-job-2.4.1
# cat xxl-job-admin/src/main/resources/application.properties
#.错误：启动报错 /data/applogs/xxl-job/xxl-job-admin.log 目录不存在
#.解决：修改log.path日志路径，将 /data/applogs/xxl-job/xxl-job-admin.log 改成 ~/xxl-job-admin/xxl-job-admin.log
sed -i "s/\/data\/applogs\/xxl\-job/\~\/xxl\-job\-admin/" xxl-job-admin/src/main/resources/logback.xml
cat xxl-job-admin/src/main/resources/logback.xml | grep "xxl-job-admin.log"
/usr/local/maven3/bin/mvn package

#.4.获取 xxl-job-admin.jar包
ll xxl-job-admin/target/xxl-job-admin-2.4.1.jar

```
