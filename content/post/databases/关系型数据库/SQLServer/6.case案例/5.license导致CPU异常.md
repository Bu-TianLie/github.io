因License限制而导致的CPU异常
===================


故障上报
----


某天DBA突然发现一台96 Cores的db服务器，在业务满负荷运行的情况下cpu只用到了40 Cores。查看 SQL Server Log 在最初几行看到如下信息：


[![Alt text](http://static.sqlfans.cn/file/20180410/mssql-case-licensing.png)](http://static.sqlfans.cn/file/20180410/mssql-case-licensing.png)


通过 `SELECT @@VERSION` 确认当前 SQL Server 实例的授权方式为 **Server \\ CAL 模式**


Microsoft SQL Server 2014 (SP2\) (KB3171021\) \- 12\.0\.5000\.0 (X64\) Jun 17 2016 19:14:09
Copyright (c) Microsoft Corporation **Enterprise Edition (64\-bit)** on Windows NT 6\.3  (Build 9600: )


解决方案
----


联系原厂要到新的license之后，将版本**从 Enterprise 升级到 Enterprise Core** 后恢复正常，下面是具体的操作步骤：


* 第1步：按下“开始”，选择 “SQL Server 安装中心”，依次选择“维护 – 版本升级”


[![Alt text](https://static.sqlfans.cn/file/20180410/mssql-setup-upgrade.png)](https://static.sqlfans.cn/file/20180410/mssql-setup-upgrade.png)


* 第2步：在“产品密钥”页上，输入对应版本的产品密钥，点下一步，直到升级完成


[![Alt text](http://static.sqlfans.cn/file/20180410/mssql-case-upgrade.png)](http://static.sqlfans.cn/file/20180410/mssql-case-upgrade.png)


* 第3步：打开ERRORLOG文件，确认没有 **detected 96 total logical processors; using 40 logical processors based on SQL Server licensing.** 提示


* 第4步：通过 `SELECT @@VERSION` 确认当前 SQL Server 实例的授权方式为 **Core\-based 模式**
