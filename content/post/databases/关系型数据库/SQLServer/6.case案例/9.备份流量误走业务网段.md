备份流量误走业务网段
==========


\[TOC]


故障上报
----


2018\.04\.21 我司每台db服务器配置了2个网段的ip地址（管理ip、业务ip），但是凌晨的备份任务触发了业务网段的流量告警。


经确认，**备份任务配置的是管理网段ip，但网络流量却分流到业务网段**。


原厂回复
----


建议禁止SMB多通道，比如发送端禁用SMB Client、接收端禁用SMB Server，重启生效。


解决方案
----


### 禁用SMB多通道


* 发送端禁用 SMB Client，在 powershell 中执行如下命令，重启服务器生效



```
Set-SmbClientConfiguration -EnableMultiChannel $false -force
Get-SmbClientConfiguration | Select EnableMultichannel
Restart-Computer

```

* 接收端禁用 SMB Server，在 powershell 中执行如下命令，重启服务器生效



```
Set-SmbServerConfiguration -EnableMultiChannel $false -force
Get-SmbServerConfiguration | Select EnableMultichannel
Restart-Computer

```
