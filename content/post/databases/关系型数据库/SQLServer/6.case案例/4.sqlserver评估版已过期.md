sqlserver评估版已过期
===============


记录一起因为SQL Server 评估版已过期导致的Alwayson Group异常。


\[TOC]


故障上报
----


* 2021\.11\.11 收到客户反馈，说生产系统Alwayson集群状态异常，利用向日葵远程到客户电脑，发现节点CPERPDB03P状态警告"未同步"


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-ag-error.png)](https://static.sqlfans.cn/file/20211112/mssql-period-ag-error.png)


分析过程
----


### 1、定位故障原因


* 登录CPERPDB03P服务器，发现 SQL Server 服务已停止，启动服务则报如下错误：


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-service-stop.png)](https://static.sqlfans.cn/file/20211112/mssql-service-stop.png)


* 打开 SQL Server Management Studio (SSMS) 则弹如下提示而无法使用：


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-ssms.png)](https://static.sqlfans.cn/file/20211112/mssql-period-ssms.png)


* 打开**事件查看器**，在 Windows日志 – **应用程序** 中看到如下代号 **17051错误**：


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-err-app.png)](https://static.sqlfans.cn/file/20211112/mssql-period-err-app.png)


* 打开**事件查看器**，在 Windows日志 – **系统** 中看到如下错误：


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-err-system.png)](https://static.sqlfans.cn/file/20211112/mssql-period-err-system.png)


### 2、确认评估版已到期


* 找到SQL Server安装目录，打开Logs目录下的ERRORLOG文件，查看输出的版本号，看到有 **Evaluation** 字样则表示目前安装的是评估版


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-err-errorlog.png)](https://static.sqlfans.cn/file/20211112/mssql-period-err-errorlog.png)


故障的原因
-----


* 若SQL Server安装文件没有没有集成序列号，同时在安装SQL Server的时候没有输入序列号，则**默认只有180天的评估试用期**。
* 若180天的评估期一到，**一旦重启SQL Server服务或者重启服务器，则 SQL Server服务就无法启动了**。同时，打开SQL Server Management Studio (SSMS) 则会弹出上面的提示而无法使用。


解决方案
----


### 3、确认已安装SQL Server的产品密钥


* 以 SQL Server 2012 为例，执行如下SQL语句：



```
exec xp_regread 'HKEY_LOCAL_MACHINE','SOFTWARE\Microsoft\Microsoft SQL Server\110\Tools\Setup','ProductCode'
exec xp_regread 'HKEY_LOCAL_MACHINE','SOFTWARE\Microsoft\Microsoft SQL Server\110\Tools\Setup','DigitalProductID'

```


> 注：ProductCode并非序列号，只要安装了SQL Server客户端就会有这个键值。而 **DigitalProductID才是序列号**，但经过了Base24编码，需要解码才能看到原始的序列号。


* 如下图示


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-get-sn-reg.png)](https://static.sqlfans.cn/file/20211112/mssql-get-sn-reg.png)


### 4、利用Powershell解码序列号


* 将以下内容保存为 d:\\get\_sql2012\_key.ps1



```
function Get-SQLServerKey {
## function to retrieve the license key of a SQL 2012 Server.
## by Xiukai Yu (78667417@qq.com)
param ($targets = ".")
$hklm = 2147483650
$regPath = "SOFTWARE\Microsoft\Microsoft SQL Server\110\Tools\Setup"
$regValue1 = "DigitalProductId"
$regValue2 = "PatchLevel"
$regValue3 = "Edition"
Foreach ($target in $targets) {
$productKey = $null
$win32os = $null
$wmi = [WMIClass]"\\$target\root\default:stdRegProv"
$data = $wmi.GetBinaryValue($hklm,$regPath,$regValue1)
[string]$SQLver = $wmi.GetstringValue($hklm,$regPath,$regValue2).svalue
[string]$SQLedition = $wmi.GetstringValue($hklm,$regPath,$regValue3).svalue
$binArray = ($data.uValue)[0..16]
$charsArray = "B","C","D","F","G","H","J","K","M","P","Q","R","T","V","W","X","Y","2","3","4","6","7","8","9"
## decrypt base24 encoded binary data
For ($i = 24; $i -ge 0; $i--) {
$k = 0
For ($j = 14; $j -ge 0; $j--) {
$k = $k * 256 -bxor $binArray[$j]
$binArray[$j] = [math]::truncate($k / 24)
$k = $k % 24
}
$productKey = $charsArray[$k] + $productKey
If (($i % 5 -eq 0) -and ($i -ne 0)) {
$productKey = "-" + $productKey
}
}
$win32os = Get-WmiObject Win32_OperatingSystem -computer $target
$obj = New-Object Object
$obj | Add-Member Noteproperty Computer -value $target
$obj | Add-Member Noteproperty OSCaption -value $win32os.Caption
$obj | Add-Member Noteproperty OSArch -value $win32os.OSArchitecture
$obj | Add-Member Noteproperty SQLver -value $SQLver
$obj | Add-Member Noteproperty SQLedition -value $SQLedition
$obj | Add-Member Noteproperty ProductKey -value $productkey
$obj
}
}

```

* 打开powershell，将 get\_sql2012\_key.ps1 文件拖入，回车，输入Get\-SQLServerKey 并回车；



```
PS C:\Users\Administrator> . D:\get_sql2012_key.ps1
PS C:\Users\Administrator> Get-SQLserverKey

```


> 注意：文件名前面有一个英文小数点.和空格，若少了这2个字符则会报错。


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-get-sn-reg-2012.png)](https://static.sqlfans.cn/file/20211112/mssql-get-sn-reg-2012.png)


### 5、找一个可用的SQL Server产品密钥


* 由于该Alwayson集群中另外2台不是评估版，所以决定在其中一个正常的节点上，挂载最初的SQL Server安装.iso文件，打开 x86 目录下的 DefaultSetup.ini 文件，可以看到原始的序列号：


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-get-sn-iso.png)](https://static.sqlfans.cn/file/20211112/mssql-get-sn-iso.png)


### 6、评估版实例导入SQL Server产品密钥


* 第1步：按下“开始”，选择 “SQL Server 安装中心”，依次选择“维护 – 版本升级”


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-setup-upgrade.png)](https://static.sqlfans.cn/file/20211112/mssql-setup-upgrade.png)


* 第2步：在“产品密钥”页上，输入对应版本的产品密钥，点下一步，直到升级完成


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-setup-sn.png)](https://static.sqlfans.cn/file/20211112/mssql-setup-sn.png)


* 第3步：打开ERRORLOG文件，查看输出的版本号，确认没有 **Evaluation** 评估版提示


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-ok.png)](https://static.sqlfans.cn/file/20211112/mssql-period-ok.png)


### 7、Alwayson集群恢复正常


* 升级完成后，顺利启动 SQL Server服务，然后打开Alwayson面板，看到故障节点状态已恢复正常


[![Alt text](https://static.sqlfans.cn/file/20211112/mssql-period-ag-ok.png)](https://static.sqlfans.cn/file/20211112/mssql-period-ag-ok.png)
