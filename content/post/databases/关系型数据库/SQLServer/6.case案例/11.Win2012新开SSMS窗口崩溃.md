Win2012新开SSMS窗口崩溃
=================


故障上报
----


2018\.05\.15\.在一台 Windows 2012 R2 的服务器上，在已打开 SQL Server Management Studio 的情况下，新开一个 New Query 窗口则 SSMS 崩溃，如下图示：


[![](https://static.sqlfans.cn/file/20180410/mssql-ssms-crash-win2012.jpg)](https://static.sqlfans.cn/file/20180410/mssql-ssms-crash-win2012.jpg)


经多次尝试，若**将 Print Spooler 服务启动**之后，新开 Query 窗口则正常。


发生原因
----


这是一个微软的bug，满足如下场景可以重现：


* OS版本：Windows 8\.1 或 Windows Server 2012 R2
* 功能：故障转移集群（Failover Cluster）已安装
* 服务：Print Spooler 服务已停止


解决方案
----


1. 安装 Windows8\.1\-KB2908806 补丁
2. 重启服务器
3. 禁用 Print Spooler 服务 \[可选]



> 参考：[SQL Server Management Studio crashes when you try to start a New Query window in Windows 8\.1](https://support.microsoft.com/en-us/topic/sql-server-management-studio-crashes-when-you-try-to-start-a-new-query-window-in-windows-8-1-e1181a06-3f22-1cf1-f244-adc9373cb363)
