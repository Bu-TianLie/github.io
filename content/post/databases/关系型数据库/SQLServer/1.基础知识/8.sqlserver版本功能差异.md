SQL Server 版本功能差异
=================


Microsoft SQL Server 各版本（WEB版、标准版、企业版）的主要功能差异如表所示：




| 功能 | WEB版 | 标准版 | 企业版 |
| --- | --- | --- | --- |
| 高可用 | 不支持 | Mirror镜像 | SQL Server 2008（Mirror）支持SQL Server 2012（Always On）支持SQL Server 2014（Always On）支持SQL Server 2016（Always On）支持SQL Server 2017（Always On）支持SQL Server 2019（Always On）支持 |
| 数据压缩 | 支持 | 支持 | 支持 |
| SQL Profiler | 支持 | 支持 | 支持 |
| 列式索引 | 不支持 | 支持 | 支持 |
| 表/索引分区 | 支持 | 支持 | 支持 |
| 变更数据捕获(Change Data Capture) | 不支持 | 支持 | 支持 |
| 并行检索操作 | 不支持 | 不支持 | 支持 |
| 分区表并行度调整 | 支持 | 支持 | 支持 |
| 透明数据加密(Transparent Data Encryption) | 不支持 | 不支持 | 支持 |
| 高级R语言集成 | 不支持 | 不支持 | 支持 |
