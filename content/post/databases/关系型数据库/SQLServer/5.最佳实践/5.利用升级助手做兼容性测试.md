利用升级助手做兼容性测试
============


在升级新版 SQL Server 之前，建议使用微软官方的 Microsoft Data Migration Assistant 扫描当前的用户数据库，分析存储过程、函数、表结构、功能等方面存在的兼容性问题，并给出解决建议及参考样例。


**下载地址**


[Microsoft® Data Migration Assistant v5\.5](https://www.microsoft.com/en-us/download/details.aspx?id=53595)


**兼容性测试过程**


1. 选择项目类型，这里Source server type及Target server type均勾选SQL Server


[![Alt text](http://static.sqlfans.cn/file/20181216/mssql-dma-using-1.png)](http://static.sqlfans.cn/file/20181216/mssql-dma-using-1.png)


1. 选择欲升级到的SQL Server版本，这里以升级SQL Server 2014为例


[![Alt text](http://static.sqlfans.cn/file/20181216/mssql-dma-using-2.png)](http://static.sqlfans.cn/file/20181216/mssql-dma-using-2.png)


1. 输入实例信息，包括ip、认证模式、账号及密码


[![Alt text](http://static.sqlfans.cn/file/20181216/mssql-dma-using-3.png)](http://static.sqlfans.cn/file/20181216/mssql-dma-using-3.png)


1. 勾选要升级的db


[![Alt text](http://static.sqlfans.cn/file/20181216/mssql-dma-using-4.png)](http://static.sqlfans.cn/file/20181216/mssql-dma-using-4.png)


1. 确认无误，点 Start Assessment


[![Alt text](http://static.sqlfans.cn/file/20181216/mssql-dma-using-5.png)](http://static.sqlfans.cn/file/20181216/mssql-dma-using-5.png)
