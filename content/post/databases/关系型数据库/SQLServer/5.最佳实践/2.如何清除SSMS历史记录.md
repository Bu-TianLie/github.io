如何清除SSMS历史记录
============


在工作中，经常使用 SQL Server Management Studio 连接本地或远程 SQL Server 服务器，时间长了可能有些名称就不用了或者重复了，SQL Server Management Studio 没有提供快捷的删除方式。但是，可以手动删除 SqlStudio.bin 文件完成对历史列表的删除。




---


\[TOC]


删除 SQL Server 2008 R2 历史服务器名称
-----------------------------


1. 先将 SQL Server Management Studio 关闭。必须先关闭，否则关闭 SQL Server Management Studio 时会再次创建 SqlStudio.bin 文件。
2. 找到如下文件，删除之。



```
C:\Users\用户名\AppData（隐藏目录）\Roaming\Microsoft\Microsoft SQL Server\100\Tools\Shell\SqlStudio.bin

```
3. 删除前，可以先备份此文件或者记录需要的服务器名称和密码。
4. 删除文件前后的效果对比如下图示：


[![Alt text](http://static.sqlfans.cn/file/20211116/mssql-ssms-clear-history.png)](http://static.sqlfans.cn/file/20211116/mssql-ssms-clear-history.png)


删除 SQL Server 2012 历史服务器名称
--------------------------


与删除 SQL Server 2008 R2 历史服务器名称方式一致，只是路径不同，具体路径为：



```
C:\Users\用户名\AppData（隐藏目录）\Roaming\Microsoft\SQL Server Management Studio\11.0\SqlStudio.bin

```
